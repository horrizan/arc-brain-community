# Arc Brain without the jargon

- **Ollama** runs the AI model on your computer.
- **n8n** is the workflow engine that connects steps together.
- **Postgres** stores task state so Arc remembers what stage an item is in.
- **Sentinel** watches folders you choose and sends new files into Arc.
- **Control Room** is the small local website where you can see items and approve actions.
- **Agents** are Markdown instruction files defining roles such as Scout or Critic. They are not separate magical programs.

You can use the core system with one local AI model. Telegram, cloud models and MemPalace are enhancements, not first-run requirements.
